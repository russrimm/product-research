# Privacy Policy

_Last updated: October 18, 2026_

Product Research ("the app") is a personal, non-commercial research project operated by @russrimm on GitHub.

## Data we access

The app uses the official X API to retrieve publicly available posts and related public metadata (for example, post text, timestamps, and public engagement counts). If you sign in with X, the app may also receive basic profile information and an access token for the permissions you approve.

## How we use data

Data is used only for personal research and analysis. It is not sold, rented, or shared with third parties, and it is not used for advertising or to profile individuals.

## Storage and retention

Data is stored in the developer's own environment and protected with reasonable safeguards. Access tokens and API credentials are kept in secure secret storage. Data is deleted when it is no longer needed.

## Your choices

You can revoke the app's access at any time in your X account under Settings > Security and account access > Apps and sessions. To request deletion of any data related to you, open an issue at [github.com/russrimm/product-research/issues](https://github.com/russrimm/product-research/issues).

## X Developer Policy

The app complies with the [X Developer Agreement and Policy](https://developer.x.com/en/developer-terms). Content deleted or made private on X is removed from the app's data when it is reasonably possible to detect.

## Changes

We may update this policy. The date above shows the latest revision.

## Contact

Open an issue at [github.com/russrimm/product-research/issues](https://github.com/russrimm/product-research/issues).
